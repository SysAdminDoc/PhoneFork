# PhoneFork v0.9.3-pre

This prerelease updates the PhoneFork and helper-app artwork with adaptive, themed monochrome, and legacy icon resources. The helper's ADB provider calls now reach their intended endpoints and keep the existing shell and system UID checks.

The helper project also includes its official Gradle wrapper, so it builds from a clean clone without a separately installed Gradle copy.

## Downloads

- `PhoneFork-v0.9.3-pre-wpf-win-x64.zip` contains the Windows desktop app.
- `PhoneFork-v0.9.3-pre-cli-win-x64.zip` contains the command-line app.
- `PhoneForkHelper-v0.9.3-pre-release.apk` is the signed Android helper.
- `PhoneFork-v0.9.3-pre.spdx.json` is the release SBOM.
- `SHA256SUMS` contains checksums for every downloadable artifact.

The Windows programs aren't Authenticode-signed and may trigger a SmartScreen warning. The helper APK is signed, but its private signing key is not included in the repository or release.
